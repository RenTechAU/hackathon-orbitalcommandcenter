01 The problem

Every satellite is shouting. There aren’t enough dishes to listen.

A satellite can only send its data down when a ground station is pointed at it — a few minutes per pass. Passes overlap. Dishes are scarce. Someone has to lose.

Today’s answer

A fixed priority table. The highest-ranked satellite wins, every single time.

It has no memory. So the satellite at the bottom of the table loses the same argument on every orbit, all day.

210 contested dish-minutes in 24 h

Measured over real orbits: 12 tracked satellites, 6 real ground stations, one full day.

The cost

Data that never comes down is data that was never collected. A weather image is worthless a day late.

And the fix can’t be “be fairer” if it delays a collision warning by even one orbit.

02 The idea

A constellation that negotiates — and remembers who gave way.

Two satellites want the same dish. Advocate agents argue it out. The system records who conceded, and uses that next time.

Contention 1 · 09:12 UTC

METOP-B and FENGYUN 3A both want EA3AGB.
No history exists.

Advocates argue. The stronger honest claim wins — and the loser is written into the graph.

Contention 2 · 10:44 UTC

The identical contention, one orbit later.
Same inputs.

Different outcome. “FENGYUN 3A yielded here last pass — its turn.”

→ and that difference is the memory

Fairness is the default, not the law. A mission-safety agent reviews every verdict and can overrule it — if the losing satellite is carrying a collision warning, it wins regardless of whose turn it was.

03 How it works

Four systems, each doing one job it can’t be removed from.

LaserData telemetry stream Positions arrive over a real Apache Iggy log. Passes open and close.
FalkorDB the memory Who yielded to whom, at which dish. Written on every decision.
Guild.ai the argument One advocate per satellite, plus a safety officer who can overrule them.
RocketRide the action Issues the tasking command and reports what mission control announces.

The query that earns a graph

MATCH path =
  (s:Satellite {name:$sat})
    -[:LINKS_TO*1..5]->
  (relay:Satellite)
    -[:IN_VIEW_OF]->
  (g:GroundStation)
RETURN path ORDER BY length(path)

A satellite over open ocean sees no dish. It routes home through laser links instead — and you don’t know how many hops until you look. Variable depth. A table needs a recursive join and breaks as the fleet grows.

The query that carries the memory

MATCH (g:GroundStation {name:$st})
    <-[:IN_VIEW_OF]-(giver:Satellite)
    -[y:YIELDED {station:$st}]->
  (recv:Satellite)-[:IN_VIEW_OF]->(g)
RETURN giver.name, recv.name, count(y)

Three hops that start and end at the same dish. History only counts between satellites contending right now — yielding to a satellite currently over the far side of the planet is irrelevant.

04 Does it actually help?

The scarcer the dishes, the more the memory matters.

Same sky, same data, same emergencies — only the scheduling policy changes. Inequality is how many more windows the busiest satellite got than the quietest. Lower is fairer.
